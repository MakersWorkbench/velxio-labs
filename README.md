# Velxio Labs

Simulator projects (`.vlx`) from the tutorials at [The Makers Workbench](https://themakersworkbench.com). Each file is a complete [Velxio](https://github.com/davidmonterocrespo24/velxio) circuit: the board, the parts, the wiring, and the sketch.

## Using a lab

1. Open the Velxio editor (the Electronics Lab on the Makers Workbench, or your own Velxio install).
2. Import the `.vlx` file from the `labs/` folder.
3. Press **Run**. The first run compiles the sketch, so give it a few seconds.

Every lab is also embedded in the tutorial that uses it, with a wiring table and step-by-step instructions.

## What is here

| Labs | Tutorial series |
| :-- | :-- |
| `Mastering-Arduino-5` to `Mastering-Arduino-10` practicals, `Mastering-Arduino-11-Lab1/Lab2` | Mastering Arduino |
| `Mastering-ESP32-01-Chip-Report` | Mastering ESP32 |
| `ESP32-*` | ESP32 tutorials (DHT22, relay, servo, ultrasonic, BMP280) |
| `DHT22-LCD-Temp-Humidity` | Arduino sensor tutorials |

Labs are added as each tutorial is published.
